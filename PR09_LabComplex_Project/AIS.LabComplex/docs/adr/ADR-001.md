# ADR-001 — модульный монолит для лабораторной АИС

Дата: 05.11.2026. Статус: принято для учебного MVP.

## Контекст

Маленькой команде нужен учет запасов и расписания без сложного развертывания.
Требуются простые транзакционные инварианты и тестируемые правила.

## Решение

Модульный монолит .NET: AIS.Core, AIS.Infrastructure, AIS.API, AIS.UI.
На этапе демонстрации хранение в памяти; следующий этап — PostgreSQL с миграциями.
Обмен с внешними системами предполагается по HTTPS/JSON.

## Последствия

Плюсы — быстрое развертывание, понятные границы, единая логика.
Минусы — ограниченность in-memory хранения, необходимость добавить OIDC и БД
до промышленной эксплуатации. Микросервисы на этапе MVP не выбираются.
