# ПР4 — JSON контракт авторизации к прибору

POST `/api/v1/equipment/access` требует `X-Demo-Key` в локальной версии.
В промышленной версии заголовок заменяется на токен OIDC Bearer.

Пример тела запроса (userId исследователя из `DemoAuth.cs`):

```json
{
  "requestId": "bc2d3ca2-7c9d-48da-96f9-2184011d4586",
  "userId": "91d8b349-1747-4b58-a0fd-2297669fbc14",
  "equipmentId": "EQ-0042",
  "action": "START_SESSION",
  "requestedAt": "2026-11-05T08:45:00Z"
}
```

Примечание: `requestedAt` должно находиться в пределах ±5 минут от времени
сервера, а бронь должна покрывать текущий момент. Токен/ключ пользователя
определяет его идентификатор, а не поле из JSON.

Коды: 200 — доступ предоставлен; 401 — неавторизован; 403 — недостаточно
прав; 404 — прибор не найден; 409 — нет активной брони; 422 — ошибка валидации.
