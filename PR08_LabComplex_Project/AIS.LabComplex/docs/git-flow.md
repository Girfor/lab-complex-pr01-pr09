# ПР5 — Git Flow

- `main`: защищенная ветка проверенных релизов.
- `develop`: интеграционная ветка текущего цикла.
- `feature/LAB-123-description`: реализация одной задачи.
- `release/1.1.0`: исправления перед выпуском.
- `hotfix/1.1.1`: аварийный патч от main.

Developer создает ветку и Pull Request. Tech Lead и Reviewer сверяют
требования, архитектуру, тесты и безопасность. Желательно минимум одно
независимое одобрение. После слияния release в main создается тег версии.

## Чек-лист PR

- [ ] Требование и критерии приемки описаны.
- [ ] `dotnet build` проходит без ошибок.
- [ ] Тестовые сценарии `AIS.Tests` проходят.
- [ ] Нет секретов, ключей и бинарных артефактов в коммитах.
- [ ] OpenAPI и ADR обновлены при изменении контрактов.
- [ ] Автор не утверждает собственный PR.
