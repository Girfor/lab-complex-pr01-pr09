## Паспорт проекта

- Вариант: 1
- Система: АИС «Лабораторный комплекс»
- Область: реактивы и бронирование лабораторного оборудования
- Технологии: .NET 8 / C# / ASP.NET Core / WPF
- Критерии MVP: прием реагента, запрет двойной брони, блокировка прибора
- Форма проверки: console demo, HTTP endpoints, встроенные тестовые сценарии

Примечание: это проектный паспорт, не свидетельство промышленного внедрения.
