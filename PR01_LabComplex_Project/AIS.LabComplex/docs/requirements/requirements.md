# ПР1 — требования и сценарии

Роли: Administrator (справочники, статус приборов, аудит),
LaboratoryAssistant (прием/списание), Researcher (поиск и бронирование).

| Код | Требование | Проверка |
|---|---|---|
| FR-01 | Реестр партий реактивов | Название, код, партия, количество, единица, срок |
| FR-02 | Прием и списание | Остаток не становится отрицательным |
| FR-03 | Бронирование оборудования | Пересечения интервалов отвергаются |
| FR-04 | Доступ по ролям | Операции запрещаются без права |
| FR-05 | Блокировка прибора | Новые брони запрещены |
| FR-06 | Журнал аудита | Содержит время, объект, действие, автора |

## Use Cases

1. Лаборант принимает реактив: ввод → проверка → создание партии или отказ.
2. Исследователь бронирует прибор: выбор периода → проверка занятости → бронь.
3. Администратор блокирует прибор: выбор карточки → статус «На обслуживании».
