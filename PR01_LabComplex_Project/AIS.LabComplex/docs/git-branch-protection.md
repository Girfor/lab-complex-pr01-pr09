# ПР9 — защита ветки main

На GitHub: Settings → Rules → Rulesets либо Settings → Branches.
Рекомендуемые правила:

1. Require a pull request before merging.
2. Require at least one approving review.
3. Require status checks: build + smoke tests.
4. Block force pushes and deletion.
5. Require conversations to be resolved.

Реальное включение требует доступа владельца к удаленному репозиторию.
В архиве оно не выполнялось, поскольку репозиторий GitHub не предоставлен.
