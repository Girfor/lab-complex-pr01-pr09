## C4 Level 2 — Containers

```mermaid
flowchart TB
    UI[WPF / MVVM AIS.UI] -->|HTTP JSON локально| API[ASP.NET Core AIS.API]
    API --> CORE[Доменное ядро AIS.Core]
    API --> INF[Адаптеры AIS.Infrastructure]
    CORE --> MEM[Память процесса для MVP]
```

## C4 Level 3 — Components and dependency rule

```mermaid
flowchart LR
    UI[ViewModels] --> CONTRACT[REST JSON]
    API[HTTP handlers] --> CORE[AIS.Core LabService]
    INF[SupplyMapper] --> CORE
    TEST[AIS.Tests] --> CORE
```

На этапе MVP используется память процесса; PostgreSQL, OIDC и система
снабжения показаны как **планируемые внешние интеграции**, не как подключенные.
